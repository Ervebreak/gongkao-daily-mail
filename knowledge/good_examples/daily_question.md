# Good Examples: Daily Question

## GQ-001 场景化基层治理题

### 示例

```text
假如你是街道工作人员，辖区正在推进一项基层治理整改工作，但部分群众认为只是“一阵风”，基层干部也反映人手不足。领导让你参与推进，你会重点做好哪些工作？
```

### 为什么好

- 有身份：街道工作人员。
- 有场景：辖区推进基层治理整改。
- 有矛盾：群众不信任、基层人手不足。
- 有任务：参与推进并提出重点工作。
- 能自然生成申论对策题、机关实务题或面试组织协调题。

### 可复用规则

今日一题不直接问“怎么看”，而是把文章主题转成具体工作场景：

```text
身份 + 场景 + 矛盾 + 任务
```

### 适用边界

适合基层治理、公共服务、民生保障、政策落实、营商环境、生态治理等文章。不适合纯人物精神、纯科技科普、纯会议报道。
