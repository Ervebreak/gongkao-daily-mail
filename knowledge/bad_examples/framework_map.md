# Bad Examples: Framework Map

## BF-001 孤立数字框架

### 反例

```text
1. 3天
2. 12人
3. 5项
```

### 问题

数字没有对象、单位、含义和结果。用户不知道这几个数字说明什么，也无法迁移到考场表达。

### 修复方式

如果必须保留数字，要写完整：

```text
通过3天集中走访，摸清12户群众的具体诉求，形成5项可跟踪整改任务。
```

## BF-002 抽象标签框架

### 反例

```text
背景 -> 问题 -> 原因 -> 对策 -> 启示
```

### 问题

这是万能空壳，没有文章信息，也不能帮助用户看懂文章结构。

### 修复方式

每个节点都要贴合原文具体内容，例如“从群众高频需求切入”“分析服务流程不顺的堵点”“提出资源下沉和部门协同”。


## BF-003 万能四段式框架

### 反例

```text
文章主线：网络法治建设在规范新技术、整顿市场秩序、保护弱势群体三个维度的协同推进。
现实矛盾：网络法治既要给狂奔的新技术套上缰绳，也要为跟不上数字节奏的群体铺好台阶。
具体路径：从问题识别、责任分工和长效反馈三个层面推进。
总结落点：把文章判断转化为可复述、可作答的治理表达。
```

### 问题

后两句是万能句，没有本篇文章独有信息；前两句重复“一句话看懂”和主线判断，不能帮助用户理解文章怎样展开。

### 修复方式

应按原文真实展开重写，例如政策解读类文章可拆成：为什么要讲、给新技术划边界、给平台竞争立秩序、给弱势群体兜底线、回到治理落点。
