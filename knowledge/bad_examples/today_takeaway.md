# Bad Examples: Today Takeaway

## BT-001 无使用场景金句

### 反例

```text
民生无小事，枝叶总关情。
```

### 问题

句子本身可以用，但如果只罗列句子，用户不知道适合哪类题、放在哪里、怎么改写。

### 修复方式

补上适用场景和用法：

```text
民生无小事，枝叶总关情。
适用：公共服务、基层治理、群众工作类题目，可放在开头表态或结尾升华。
用法：说明基层工作要从群众最具体的需求做起。
```

## BT-002 只有公文套话

### 反例

```text
要持续完善体制机制，系统推进资源整合，形成多元协同工作格局。
```

### 问题

看起来正式，但不好背、难复述，也不像普通考生自然写出来的话。

### 修复方式

改成更像高水平考生的表达：

```text
做好基层服务，不能只靠一个部门单打独斗，而要把资源、责任和流程接起来，让群众遇到问题时有人管、能解决。
```

## BT-003 金句和适用场景被截成半句话

### 反例

```text
政策制定不能只算部门账，必须建立出台前的横向交叉审查机制，防止局部合理
用主动服务化
用于强调执法理
```

### 问题

- 句子没有完整谓宾结构。
- 适用场景也被截断，用户不知道“执法理”后面要表达什么。
- 这类问题通常来自固定字数裁剪，不是模型单次偶然写差。

### 修复方式

```text
政策制定不能只算部门账，更要算整体账；出台前多做横向审查，才能防止局部合理叠加成全局矛盾。
适用：政策落实、部门协同、基层减负类题目，可用于说明制度设计要先做统筹校验。
```

### 可复用规则

金句、适用场景、常识点、可迁移框架都必须完整收束。宁可改短，不得硬裁。

## BT-004 未核实政策事实

### 反例

```text
司法部联合生态环境部与应急管理部出台专项执法意见，要求涉企检查扫码入企。
```

### 问题

这类表达看起来权威，但如果原文没有明确部门、文件名和发布时间，就属于未支撑强事实，容易误导用户。

### 修复方式

```text
规范涉企执法的核心，是用留痕、公开和问责压缩随意检查空间。
```

### 可复用规则

原文未明确出现具体文件名、部门名、发布时间、政策名称时，不得生成“某部门联合出台某文件”式表述。
