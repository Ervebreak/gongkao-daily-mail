# Bad Examples: Daily Question

## BQ-001 过宏大题目

### 反例

```text
你怎么看高质量发展？
```

### 问题

- 没有身份。
- 没有场景。
- 没有现实矛盾。
- 没有明确任务。
- 像泛泛讨论题，不像申论或面试训练题。

### 修复方式

把宏大主题转成具体执行场景：

```text
假如你是县直部门工作人员，当地推进产业升级时遇到企业顾虑、人才不足、配套不完善等问题。领导让你参与调研并提出建议，你会重点做好哪些工作？
```

## BQ-002 题干只有观点，没有任务

### 反例

```text
基层治理现代化需要提升服务能力，请谈谈你的理解。
```

### 问题

这类题看似贴近主题，但只让用户“谈理解”，没有把文章变成可训练的工作任务。

### 修复方式

改成“具体场景 + 具体矛盾 + 具体任务”，例如群众不理解、部门协同慢、基层资源不足，然后要求提出推进办法、整改建议或沟通方案。

## BQ-003 题型标注和题干气质错位

### 反例

```text
题型：申论对策题
题目：作为市营商环境局工作人员，领导交由你负责该制度的落地优化与宣传督导，你将如何开展工作。
```

### 问题

- “作为某岗位工作人员”“领导交由你”“如何开展工作”更像机关实务或面试执行类任务。
- 如果只标“申论对策题”，用户会误判作答口径。
- 题型标签与答案结构不一致时，会影响训练价值。

### 修复方式

根据呈现方式二选一：

```text
题型：机关实务题 / 申论对策题
```

或把题干改成材料式申论问法：

```text
某市推行涉企执法扫码入企制度，推行初期出现执法人员嫌流程繁琐、企业担心走形式等问题。请提出优化落实的对策建议。
```
