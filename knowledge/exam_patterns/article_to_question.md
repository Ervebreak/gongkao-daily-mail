# Article To Question Patterns

本文档沉淀“官方文章 -> 今日一题”的转换方法。

## 四步转换法

```text
1. 抓文章主线：这篇文章到底在讲什么治理问题？
2. 找考场主题：它能迁移到申论/面试的哪个高频主题？
3. 造真实场景：把主题放进基层、部门、窗口、调研、整改、服务等场景。
4. 设明确任务：要求提出建议、推进办法、沟通方案、调研思路或整改措施。
```

## 文章类型到题型

| 文章类型 | 优先题型 | 转换方向 |
| --- | --- | --- |
| 基层治理 | 申论对策题 / 面试组织协调题 | 群众诉求、部门协同、整改落实 |
| 公共服务 | 申论综合分析题 / 对策题 | 服务短板、流程优化、资源下沉 |
| 产业发展 | 申论分析题 / 调研建议题 | 因地制宜、场景牵引、企业需求 |
| 生态治理 | 对策题 / 综合分析题 | 保护与发展、群众收益、长效机制 |
| 精神价值 | 面试综合分析题 / 大作文立意 | 青年担当、岗位实践、知行合一 |
| 政策评论 | 综合分析题 / 贯彻执行题 | 政策意义、落实堵点、执行路径 |

## 禁止转换

- 不要把所有文章都转成“你怎么看”。
- 不要把所有题都写成面试口吻。
- 不要把文章标题直接改成题目。
- 不要考冷门专业细节。
- 不要脱离文章另起炉灶。

## 好题检查

一个好题至少应回答：

- 用户扮演谁？
- 发生在什么场景？
- 面临什么矛盾？
- 要完成什么任务？
- 和原文主题有什么关系？
