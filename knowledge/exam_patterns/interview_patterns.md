# Exam Patterns: 面试题型

## 组织协调题

适用文章：活动开展、政策宣传、基层服务、专项行动。

常用框架：

```text
明确任务 -> 分工协同 -> 推进执行 -> 总结反馈
```

## 群众沟通题

适用文章：民生服务、基层治理、政策落地、矛盾化解。

常用框架：

```text
稳定情绪 -> 核实情况 -> 解释处理 -> 后续反馈
```

## 应急应变题

适用文章：突发问题、舆情回应、现场处置、风险治理。

常用框架：

```text
控制局面 -> 查清原因 -> 分类处理 -> 复盘改进
```

## 综合分析题

适用文章：政策评论、社会现象、价值判断。

常用框架：

```text
亮明态度 -> 分析原因 -> 说明影响 -> 提出做法
```
