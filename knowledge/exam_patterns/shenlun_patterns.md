# Exam Patterns: 申论题型

## 对策建议题

适用文章：基层治理、公共服务、政策落实、营商环境、生态治理。

转换方法：

```text
文章问题 -> 现实场景 -> 执行身份 -> 推进任务
```

常用框架：

```text
摸清情况 -> 找准问题 -> 分类施策 -> 跟踪落实
```

## 综合分析题

适用文章：政策评论、现象分析、发展理念、治理判断。

转换方法：

```text
文章观点 -> 争议或现象 -> 要求分析意义、问题、原因、对策
```

常用框架：

```text
表明态度 -> 分析意义或问题 -> 分析原因 -> 提出建议
```

## 贯彻执行题

适用文章：政策部署、活动方案、调研整改、群众宣传。

转换方法：

```text
文章要求 -> 具体单位任务 -> 形成讲话稿、倡议书、调研提纲、整改方案
```

常用框架：

```text
明确目的 -> 分清对象 -> 安排内容 -> 落实保障
```
