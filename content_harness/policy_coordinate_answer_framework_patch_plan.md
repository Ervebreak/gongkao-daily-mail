# 政策坐标与作答框架质量补丁

本分支承接 2026-06-02 候选邮件暴露出的三个小问题。

## 1. 政策坐标低匹配隐藏

若政策坐标没有匹配到与文章高度契合的政策语句，前台不展示该模块。宁可缺省，也不要硬凑。

建议门槛：

- `policy_match_score < 60`：不展示。
- `source_type == policy_only` 且 `policy_match_score < 65`：不展示。
- 主题明显错位：不展示。
- `answer_angles` 出现半截或拼接残句：不展示。

## 2. original_reading_focus 语义完整性

在现有清洁和截断约束里补充残词检测，不能只补句号。

典型残词：

- 责任主
- 这是……最
- 畅通维
- 信息透明
- 清退四
- 制度保

## 3. daily_question.answer_framework 骨架化

在现有提示词和质检规则中加入优秀范本，要求 `answer_framework` 使用“动作标签：关键词短句”的骨架结构。

优秀范本：

- 问题排查：清理擦边商品，梳理平台审核漏洞。
- 准入审核：建立上架红线，强化人工复核。
- 购买限制：实名验证、监护授权，阻断未成年人触达。
- 监管闭环：常态抽查、约谈通报，提高违规成本。

## 不改范围

- 不改发送逻辑。
- 不改模型配置。
- 不改门禁策略。
