# 自动校验与回退

## 自动校验的边界

脚本只判断确定性问题：必填结构、明显占位文本、材料依赖词、框架数量和长度、题型身份的基础信号、明显截断、文本长度和可选模块格式。

它不能替代对文章理解、政策高度匹配、题目是否真正跑题、权限是否实质越界或跨模块语义重复的审核判断。这些必须交由独立审核技能与项目总门禁复核。

## 使用

对候选 JSON 运行：

```bash
python skills/gongkao-morning-reading-generation/scripts/validate_candidate_contract.py candidate.json --report candidate.contract-report.json
```

有 error 时不得把候选交给渲染；先按报告字段修复。warning 可进入独立审核技能判断。随后仍需运行项目既有的 `scripts/validate_daily_brief.py` 与最终渲染检查。

## 回退矩阵

| 问题根因 | 操作 |
| --- | --- |
| 主文低分、正文/来源无法核验、转化勉强 | 回到选文 |
| 结构图不忠实原文 | 仅重拆结构图 |
| 今日一题跑题、字段缺失、身份边界不稳 | 仅重写今日一题 |
| 总结表达不考生化、重复或截断 | 仅重写对应表达字段 |
| 政策出处不可靠或弱匹配 | 隐藏政策模块 |
| 修复引入新事实或新 P0 | 回退修复前版本并人工复核 |

修复后必须重渲染完整 HTML、简版 HTML 和纯文本，重跑确定性检查、项目质量门禁和独立审核。不得通过降低门禁等级来让候选通过。
